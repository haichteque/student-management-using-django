# Student Management System - Automated & Tested

**A DevOps & QA Showcase Fork**

This repository is a fork of the [Original Django Student Management System](https://github.com/jobic10/student-management-using-django) created by Owonubi Job Sunday (jobic10). 

While the original project provides a robust foundational application built with Django, **this fork focuses on elevating the project through modern DevOps practices, automated testing, and continuous integration/continuous deployment (CI/CD).**

---

## 🚀 Key Achievements & Contributions in this Fork

This version of the project has been enhanced with a focus on reliability, code quality, and deployment automation. Maintained by Huzaifa, the following infrastructure and testing suites have been successfully integrated:

### 1. Full CI/CD Pipeline Integration
- Implemented a complete Continuous Integration and Continuous Deployment pipeline.
- Automated the build, test, and deployment processes to ensure that new code integrations do not break existing functionality.
- Ensures highly reliable and repeatable deployments.

### 2. Comprehensive Unit Testing
- Added robust unit tests for the Django backend.
- Covered critical business logic, models, and views to ensure data integrity and system stability across all user roles (Admin, Staff, Student).

### 3. End-to-End (E2E) Testing with Cypress
- Integrated **Cypress** to simulate real user interactions and guarantee a seamless frontend experience.
- Automated UI testing for critical flows, including login, attendance tracking, result management, and dashboard rendering.

## 🌟 Original Project Features

The core application retains all the excellent features developed by the original author:

### A. Admin Capabilities
- Overall Summary Charts of Student/Staff Performances, Courses, Subjects, Leave, etc.
- Manage Staff, Students, Courses, Subjects, and Sessions (CRUD operations).
- View Student Attendance and Review/Reply to Feedback and Leave applications.

### B. Staff/Teacher Capabilities
- Take/Update Student Attendance and Add/Update Results.
- View Summary Charts for their specific subjects and students.
- Apply for Leave and Send Feedback to the HOD.

### C. Student Capabilities
- View Attendance and Results.
- View Summary Charts related to their performance.
- Apply for Leave and Send Feedback to the HOD.
